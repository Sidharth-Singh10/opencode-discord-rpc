# M0 — packaged-host and transmission spike (rework)

Status: **rework implemented and validated**. The M0 gate is **not accepted by
the Jury** and remains open on the human visual check; remote integration is
**descoped and unverified**. Nothing was published to npm.

This document records the second pass after the Critic review. It describes only
what was observed on the packaged artifact in the lab.

## What changed in this pass

1. Startup arbitration now always arms the retry timer. A schema write lock at
   startup is recovered by the production timer, with no auxiliary ticker.
2. Evidence capture is a fixed, runtime-validated allowlist. Arbitrary object
   keys are never traversed and exception text is never serialized. Observer
   errors carry a fixed code only.
3. The evidence validator requires complete, strictly typed documents, a full
   owner/fence timeline, at least five acknowledged writes, same-session
   repeats ≥4 s apart, anchor conversion, per-instance coverage and a complete
   positive fixture. Negative tests cover each tampering class.
4. Closing the IPC during a handshake settles the pending connect promise.
5. Locality fails closed: missing, empty or ambiguous identity is `unknown` and
   refuses enrichment. Only a complete hostname + all-loopback URL proof is
   `local`.
6. Timestamps are selected immediately before a publication attempt and
   committed **only after acknowledgment** in a shared coordination anchor
   table. Inspection and failed sends never commit; later messages, reloads
   and takeovers preserve the anchor.
7. Coverage is reported per instance and per stream, with distinct event IDs
   and observer errors excluded from the real type count.
8. Test-only control paths were removed from the distributed bundle; the pack
   guard scans for them.
9. Visual rendering remains unverified.

`src/tui.tsx` is deliberately still ~600 lines: it is isolated M0 spike
orchestration and M1 replaces it; no cosmetic reduction was attempted.

## Timestamp lifecycle

- Source: `session.message.list[].type=user.time.created`
- Units: milliseconds since Unix epoch; conversion `floor(ms/1000)`
- Selection: immediately before the first publication attempt that succeeds
- Commit: only after a non-ERROR RPC acknowledgment
- Storage: `anchor` table in the coordination DB, keyed by a hash of
  server identity + session ID (server-qualified)
- Inspection, failed sends and refused operations never commit
- Later user messages, republishes, `/reload` and ownership changes read the
  committed anchor

## Identity paths

- **local**: complete hostname + all-loopback URLs; enrichment allowed.
- **remote**: differing hostname or non-loopback URL; enrichment refused.
- **unknown**: missing/empty/malformed identity or an unavailable `server.info`;
  enrichment refused, publication continues events-only.

Packed-host evidence of the unknown path: a lab-only identity-hiding proxy
answered `/api/info` with an incomplete document (no hostname, empty URLs).
The installed package recorded `class: unknown`, `enrichment: refused`,
`serverFingerprint: null`, and still published twice at fence 6. The proxy is
a test harness, not package code.

Remote integration is **descoped from M0 and unverified**; `remote.json` records
`status: descoped`, `integration: unverified`, `claimed: false`.

## Privacy

Capture is a fixed allowlist:

- fixed envelope keys only;
- fixed structural paths per known event type (unknown types get only the
  envelope);
- fixed canonical status/outcome/reason/model/agent/reply/executed values,
  runtime-validated;
- hashed event/session/location identifiers and an instance ID;
- no traversal of `input`, `content`, `error`, `metadata`, `credentials` or any
  other arbitrary object;
- observer failures: fixed code `capture-listen-failed`, no exception text;
- probe/locality: booleans, counts, enums and a fingerprint hash only; no raw
  URLs, hostnames, paths, stacks or error messages.

Live canaries: prompt, tool output, permission resource, error content and
`question` form header/content. Additionally the capture unit tests plant
`data.credentials.M0CANARY_UNHANDLED_SECRET`; it never appears because the
object is not traversed. Five live canaries, 24 evidence files scanned,
**0 leaks**.

## Validator and negative tests

`scripts/m0-evidence.ts` is strict and exports `validateEvidence(dir)`:

- mandatory `run.json`/`probe.json`/`locality.json`/`remote.json`/
  `coverage.json`/`reload.json`/`canaries.json`, JSONL streams and snapshots;
- exact key sets, types and enums; null/array/malformed/incomplete documents
  fail;
- complete scenarios with values (failed turn, user cancellation, permission,
  compaction, form, tool, location shutdown, reload, cleanup, disconnect,
  reconnect);
- READY, at least five acknowledged writes, nonce/evt/activity, executed-model
  and timestamp provenance, session identity, owner identity and fence;
- owner intervals: no writes before acquisition or after release/revocation,
  no overlapping owners, no stale/mismatched fence, no refused operation with
  a nonce;
- same-session anchor equality and a repeat ≥4 s;
- conversion check `floor(originalValue_ms / 1000)`;
- local/remote/unknown enrichment rules, invalid enums, and no unsupported
  remote-success claim.

`test/validator.test.ts` runs the CLI against a complete positive fixture and
48 negative mutations; each negative exits nonzero. `bun test` covers the
payload, redaction, framing, handshake cancellation, publisher startup
recovery, contention/takeover, anchor lifecycle and real subprocess
SIGKILL/SIGSTOP.

## Limitations / unresolved

1. **Visual card unverified.** RPC acknowledgment is not render proof. A human
   must check image, both hover texts and the anchored timer; native acks do not
   close this gate.
2. **Remote integration unverified and descoped.** No genuine remote endpoint
   was tested.
3. `session.idle`/`session.status` absence is sampled. It is not a promise for
   every host configuration.
4. Event-stream reconnect after a server restart was not signalled by a second
   `server.connected`; the Discord socket reconnect was exercised by
   disconnect → publish (same instance, READY twice).
5. The held-write-lock takeover test uses an external locker process because
   test hooks were removed from the bundle. It proves lock contention delays
   takeover; it is not the same as a publisher SIGSTOPped inside its own
   critical section.
6. The unknown-identity evidence uses a lab proxy. It is packed-host evidence
   of the branch, not evidence about a remote network.
7. Capture is a sample, not a completeness proof. Per-instance gaps are
   reported.
8. The pack guard is heuristic; dependency-graph enforcement is M1.
9. npm publication was not performed.

## Gate result

Every testable M0 item in this environment passes (validator exit 0). The
overall M0 gate is **not accepted**: the human visual check is open and remote
integration is unverified/descoped. The Jury owns acceptance.
